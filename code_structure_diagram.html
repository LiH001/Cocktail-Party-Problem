项目代码结构与数据流

四层结构组织实验：数据生成、核心算法、训练评估、GUI 展示

数据脚本 核心包 实验脚本 GUI
Layer 01

数据生成脚本

prepare_librispeech_clean.py 将 LibriSpeech FLAC 整理为按说话人划分的 clean WAV。
build_dataset_manifest.py 生成 mixture、source、noise 和 manifest.jsonl。
split_manifest.py 拆分 train.jsonl / valid.jsonl，形成训练与验证入口。
Layer 02

核心算法包

audio.py / dataset.py 音频读写、STFT、ISTFT、特征提取和训练目标构造。
deep_clustering.py BLSTM 模型、Embedding 分支、Soft Mask 分支、PIT 损失。
metrics.py SI-SDR、Delta SDR 和最优说话人排列匹配。
Layer 03

训练评估脚本

train_deep_clustering.py 训练 Easy / Hard 模型，保存 checkpoint 和训练日志。
generate_deep_clustering_demo.py 生成 demo_audio、metrics.csv 和 metrics_all.csv。
evaluate_*.py 评估分离结果和 Oracle 理想掩码理论上限。
Layer 04

GUI 展示界面

Demo Compare 播放 mixture、source、separated，并显示 SDR 指标。
Waveform / Spectrogram 可视化混合语音和分离输出的时频结构。
Custom Separation 加载 checkpoint，对项目音频或上传音频进行分离。

统一输出产物

实验脚本和 GUI 共享同一组产物，避免重复计算，方便报告分析。

data/ 原始语音、clean speakers、Easy/Hard 混合数据。
outputs/*.pt 训练得到的 latest / best checkpoint。
outputs/logs/ epoch loss、SDR_in、SDR_out、Delta SDR。
demo_audio_*/ 展示样例音频、metrics.csv、metrics_all.csv。
paper/ LaTeX 报告、图片素材和最终 PDF。
数据流向： 数据脚本生成 manifest 与 wav，核心包读取并构造特征，实验脚本训练和评估模型，GUI 读取 checkpoint、音频和 CSV 指标进行交互展示。
工程设计： 训练、评估和 GUI 之间通过文件产物解耦，既保留命令行实验的可复现性，又方便进行听觉和视觉展示。
